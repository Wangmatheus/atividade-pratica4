# atividade-pratica4
Atividade Prática IV - Desenvolvimento Web I

Este repositório contém a resolução da Atividade Prática IV da disciplina de Desenvolvimento Web I. O objetivo principal é aplicar conceitos avançados de estruturação de layouts responsivos utilizando CSS Grid, Flexbox e Media Queries para a construção de interfaces web adaptáveis.

🎯 Objetivos da Atividade
Desenvolver páginas web responsivas.
Aplicar conceitos de CSS Grid para organização de layouts.
Utilizar Flexbox para alinhamento e distribuição de elementos.
Adaptar interfaces para diferentes dispositivos utilizando Media Queries.
Praticar a separação entre estrutura (HTML) e apresentação (CSS).
▶️ Como Executar

Clone este repositório:

git clone <url-do-repositorio>
Acesse a pasta da atividade desejada.
Abra o arquivo index.html em um navegador web.
